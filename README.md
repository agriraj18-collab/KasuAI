# 🪙 KasuAI — குடும்ப நிதி & AI மேலாண்மை
**Smart AI Family Finance, Intelligent SMS Brain & Dual-User Budget Tracker**

---

## 🌟 அறிமுகம் (About KasuAI)
**KasuAI (காசு AI)** என்பது குடும்ப நிதி மேலாண்மை, வங்கி/UPI குறுஞ்செய்திகளை (SMS) AI மூளை மூலம் தானாகப் படித்து எளிய தமிழில் விளக்குதல், கணவன்-மனைவி பகிரப்பட்ட பட்ஜெட், கடன்/EMI கண்காணிப்பு மற்றும் மாதாந்திர குடும்ப நிதி அறிக்கை தயாரிக்கும் ஒரு அதிநவீன நிதிச் செயலி.

---

## 🚀 முக்கிய அம்சங்கள் (Key Features)

1. **🧠 KasuAI ஸ்மார்ட் SMS மூளை (Hybrid AI Brain):**
   - **Google Gemini Flash AI:** வங்கி SMS-களைப் படித்து தொகை, கடை/நிறுவனம், மற்றும் செலவுப் பிரிவை 1 வினாடியில் தானாக வகைப்படுத்தும் திறன்.
   - **Fallback Rule Engine:** இன்டர்நெட் அல்லது API இல்லாவிட்டாலும் உடனே இயங்கும் தானியங்கி ரெஜெக்ஸ் என்ஜின்.

2. **🤖 தமிழ் AI நிதி ஆலோசகர் (AI Family Financial Advisor):**
   - மாத இறுதியில் உங்கள் குடும்பச் செலவு, சேமிப்பு மற்றும் மனைவி பட்ஜெட்டை அலசி, எளிய தமிழில் நடைமுறை ஆலோசனைகள் வழங்கும் நுண்ணறிவு அறிக்கை.

3. **📊 நேரலை டேஷ்போர்டு (Live Dashboard):**
   - மாதாந்திர மொத்த செலவு, பரிவர்த்தனைகள் எண்ணிக்கை.
   - 👩 **மனைவி வீட்டு பட்ஜெட் (₹40,000):** செலவிடப்பட்ட தொகை, ஊடாடும் புரோக்ரஸ் பார் மற்றும் கையில் மீதமுள்ள இருப்பு.
   - 💰 **மாத சேமிப்பு நிலை (₹65,000 இலக்கு):** நிகர சேமிப்பு கால்குலேட்டர்.
   - 🍩 Plotly மூலமான துறைவாரியான ஊடாடும் செலவு வட்ட வரைபடம்.

4. **⚡ ஒரு-க்ளிக் நேரடிச் செலவு பட்டன்கள் (Quick Action Presets):**
   - ☕ டீ/ஸ்நாக்ஸ் ₹20, 🥛 பால் ₹35, 🥦 காய்கறி ₹150, ⛽ பெட்ரோல் ₹200, 🌾 மளிகை ₹500 ஆகியவற்றை ஒரே தட்டலில் பதிவு செய்யலாம்.

5. **🏦 கடன்கள் & EMI கண்காணிப்பு (Loans & EMI Tracker):**
   - புதிய கடன்கள் சேர்த்தல், அசல் இருப்பு, தவணை தேதி மற்றும் மீதமுள்ள மாதங்கள் மேலாண்மை.
   - மாத மொத்த EMI மற்றும் மொத்தக் கடன் நிலுவை சுருக்கம்.

6. **📁 பழைய SMS & வங்கி அறிக்கைகள் பதிவேற்றம் (Bulk Import):**
   - **XML:** Android *SMS Backup & Restore* கோப்புகள்.
   - **JSON:** SMS பேக்கப் ஏற்றுமதிகள்.
   - **CSV:** SBI, HDFC மற்றும் பிற வங்கி அறிக்கைகள் அல்லது கிரெடிட் கார்டு ஸ்டேட்மென்ட்கள்.

7. **🔔 இதர எச்சரிக்கைகள் காப்பகம்:**
   - செலவு அல்லாத OTP, வங்கி மேண்டேட் (UPI Mandate), பங்குச் சந்தை டிப்ஸ் போன்றவற்றைத் தனியாகப் பிரித்து தமிழில் விளக்கம் அளித்தல்.

## 🛠️ நிறுவுதல் மற்றும் இயக்குதல் (How to Run)

### 1. தேவைகளை நிறுவ:
```bash
cd ~/Downloads/RAJPWA
pip3 install -r requirements.txt
```

### 2. KasuAI செயலியை இயக்க:
```bash
python3 -m streamlit run app.py
```
உலாவியில் திறக்கவும்: `http://localhost:8501`
